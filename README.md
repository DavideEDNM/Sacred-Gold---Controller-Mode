# 🎮 Sacred Controller — Sacred Gold / Underworld

> **Driver di emulazione controller per Sacred Gold & Underworld**
> *Developed by DavideEDNM for Sacred Online Community*

`Sacred Controller` è un'utility leggera in C# progettata per giocare a **Sacred** utilizzando qualsiasi joypad moderno (Xbox / XInput) o generico (PlayStation / DirectInput USB).

---

## 🌟 Caratteristiche Principali

* 🕹️ **Supporto Universale Controller**: Compatibilità nativa sia con **XInput** che **DirectInput**.
* 🎯 **Movimento e Cursore Intuitivi**: Levetta Sinistra per il movimento del personaggio e Levetta Destra per la mira libera del cursore.
* 🧪 **Gestione Rapida Pozioni**: Slot rapido per pozioni di Salute, Mana, Antidoto, Elisir e Morte Non-Morti.
* ⚔️ **Cambio Armi e Skill Dinamico**: Combinazioni di tasti (`LB`/`RB` + D-Pad) per selezionare rapidamente le 4 armi e le 4 arti da combattimento.
* 🚀 **Launcher Integrato**: Ricerca(Manuale) ed esegue automaticamente l'eseguibile di Sacred.

---

## 🎮 Mappatura Comandi

| Pulsante Controller | Azione in Gioco | Tasto Emulato |
| :--- | :--- | :--- |
| **Levetta LS** | Movimento Personaggio | Cursore Mouse |
| **Levetta RS** | Mirata Libera / Cursore | Cursore Mouse |
| **Grilletto RT (R2)** | Attacco Principale | Clic Sinistro |
| **Grilletto LT (L2)** | Skill Selezionata | Clic Destro |
| **Pulsante A (✖)** | Selezione / Interazione | Clic Sinistro |
| **Pulsante B (🔴)** | Annulla / Menu | Clic Destro |
| **Pulsante X (⬛)** | Raccogli Bottino | `A` |
| **Pulsante Y (▲)** | Apri Inventario | `I` |
| **Dorsale RB (R1)** | Pozione Salute | `Spazio` |
| **Dorsale LB + RB** | Pozione Mana | `W` |
| **D-Pad SU** | Pozione Mana | `W` |
| **D-Pad GIÙ** | Antidoto | `E` |
| **D-Pad SX** | Elisir Concentrazione | `R` |
| **D-Pad DX** | Morte Non-Morti | `T` |
| **LB + D-Pad** | Selezione Armi (Slot 1 - 4) | `1`, `2`, `3`, `4` |
| **RB + D-Pad** | Selezione Skill (Slot 1 - 4) | `6`, `7`, `8`, `9` |
| **LS / L3** | Menu Arti da Combattimento | `S` |
| **RS / R3** | Registro Missioni | `L` |
| **Select / Back** | Mappa del Mondo | `M` |
| **Start** | Menu di Pausa | `ESC` |

## 🚀 Come Utilizzare

1. Scarica l'ultima versione di `Sacred Controller.exe` dalla sezione **Releases**.
2. Avvia `SacredController.exe`.
3. Collega il tuo controller al PC.
4. Seleziona l'eseguibile principale di Sacred (`Sacred.exe`) tramite la finestra di dialogo.
5. Inizia a giocare!
